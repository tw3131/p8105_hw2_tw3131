### Dataset Description

The dataset contains information about NYC subway station entrances and
exits, including subway lines, station names, station latitude and
longitude, routes served, entry permission, vending availability,
entrance types, and ADA accessibility.

I cleaned the data by standardizing variable names using
janitor::clean_names(), selecting the relevant variables using select(),
and converting the entry variable from character (“YES” and “NO”) to
logical (TRUE and FALSE) using mutate() and case_match().

The resulting dataset contains 1,868 rows and 19 columns.

The data are not fully tidy because route information is spread across
multiple columns (route1 to route11) rather than being organized into
separate variables for route number and route name.

variables, including data from Mr. Trash Wheel, Professor Trash Wheel,
and Gwynnda. Each observation represents a dumpster collection record.
Key variables include the Trash Wheel identifier, collection date,
weight of trash in tons, volume in cubic yards, and counts of different
types of trash, such as plastic bottles and cigarette butts.

The data were cleaned by standardizing variable names, removing
non-dumpster-specific summary rows, converting variable types where
necessary, and combining the three datasets. Based on the available
data, Professor Trash Wheel collected a total of 294.96 tons of trash,
